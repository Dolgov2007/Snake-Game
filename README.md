# Змейка
Добро пожаловать в консольную игру Змейка!

## Описание
Вам предстоит управлять Змейкой, которая движется по полю 19 на 19, окружённое стенами.
Цель - съесть как можно больше яблок (), избегая столкновения с границами (█) и собственным хвостом (○)

## Как запустить?
0. Убедитесь, что у вас установлен .NET SDK
1. Скачайте всё содержимое репозитория к себе на устройство
2. Откройте терминал в корневой папке игры
3. Выполните команду "dotnet run"
4. Игра запустится на консоли - следуйте инструкциям на экране

## Особенности игры
- Меню с выбором уровня сложности
- Цветное игровое поле
- Динамическая сложность
- Подсчёт очков и времени игры
- Поддерживается ввод как с латиницы так и с кириллицы

## Управление 
W / Ц - вверх <br>
S / Ы - вниз <br>
A / Ф - влево <br>
D / В - вправо <br>
E / Escape / У - выход из игры <br>
