# Змейка
Добро пожаловать в консольную игру Змейка!

## Описание
Вам предстоит управлять Змейкой, которая движется по полю 19 на 19, окружённое стенами.
Цель - съесть как можно больше яблок (''), избегая столкновения с границами поля и собственным хвостом.

## Особенности игры
- Реализовано меню с выбором уровня сложности
- Динамическая сложность (с каждым съеденным яблоком скорость Змейки возрастает)
- Подсчёт очков и времени игры
- Поддерживается ввод как с латиницы так и с кириллицы

## Управление 
W / Ц - вверх
S / Ы - вниз
A / Ф - влево
D / В - вправо
E / Escape / У - выход из игры
